# Data attribution

The derived star caches in this directory use HYG Database v4.1 by David Nash / Astronexus, pinned to commit `3bf37f4b2d5460e1278286320d1d62fab9b493c1`. HYG is licensed under [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). These derived catalogue data are distributed under the same licence.

Host-system coordinates and distances come from the [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/) Planetary Systems Composite Parameters table. See `manifest.json` and the repository files `data/source/sky/hyg-source.json` and `data/source/sky/featured-hosts-nasa.json` for exact versions, queries, checksums, assumptions, and limitations.
